# Windows 修复与阅读器优化验收（2026-10-29）

本次更新基于 0.10.0 开发版，包含 Windows 测试失败修复及实际交接案例试用后实施的优化。本文记录已执行的验证与范围；完整原始日志、截图、案例状态和导出样本保留在本地，不进入公开仓库。

## 已完成的修改

- 修复 SQLite 迁移备份和权限探测中的连接释放，避免 Windows 文件占用；修正跨平台命令、UTF-8 和测试数据隔离。
- 统一 Windows 普通、扩展盘符及 UNC 路径的边界比较；修复首次并发登记的配置锁竞争；在写入前检查配置、状态、数据与项目目录隔离。
- 区分附件操作错误与连接状态，轮询不再清除文件错误；手动刷新更新当前附件详情并保留阅读位置，过期响应不覆盖新选择。
- 自动展示记录不再确认已读；主动选择确认阅读，并可标回未读。
- 搜索解码后的可见字段、完整记录编号和文件路径，避免匹配内部 JSON 字段；保持分页稳定，并修复删除任务标签后的历史任务筛选。
- 提供会话查询、恢复候选和恢复命令，同名任务显示区分信息；新增 `status/resume --summary`，保留完整输出兼容性。
- 附件保存失败提供具体索引、输入路径、解析路径与原因，保持原请求重试和原子保存语义。
- 新记录保存有界文件指纹并显示版本变化；用户可主动保存当前文件的证据副本；验证标签明确为记录者报告。
- 原生保存和浏览器下载使用统一的中文友好文件名，并处理 Windows 无效字符、保留名和长度。
- 在 HTTP 响应写入边界处理 Windows 客户端连接中止，其他服务器错误仍然暴露。

## 实际验证

环境：Windows、Python 3.11.5、SQLite 3.41.2、Textual 6.12.0、pywebview 6.2.1；Edge 156.0.4314.42、WebView2 Runtime 155.0.4283.62。

| Python 全量套件 | 382 项，0 失败、0 错误、4 跳过 |
| 最终无界面套件 | 291 项，0 失败、0 错误、4 跳过，未导入 Tk |
| 最终阅读模型定向回归 | 15 项，0 失败、0 错误、1 项既有权限跳过 |
| 真实 Edge Web UI | 12/12 组通过，未捕获前端异常 0；390/800/1280 像素视口检查通过 |
| WebView2 与 Windows 原生另存为 | 11/11 项通过，未捕获前端异常 0，退出码 0 |
| 当前 editable 安装工作流 | 初始化、记录、重放去重、冲突、附件清单、源文件保持、会话和阅读资源检查通过 |
| 公开源码与补丁检查 | 公开源码检查无发现，`git diff --check` 通过 |

全量套件执行于最后的历史任务筛选单行修复之前；该修复之后重新执行了完整无界面套件和阅读模型定向回归。各套件包含重叠用例，数量不能累加为独立测试总数。4 项跳过与修复前相同：3 项因当前账户不具备符号链接权限，1 项为 Linux 专属检查；没有新增跳过。Windows junction 边界测试实际运行通过。

原生导出通过真实系统对话框选择中文目录及带空格的文件名，并点击保存。生成文件为 742 字节，UTF-8 严格解码成功，中文字段正常，按文本换行规则读取后与阅读模型生成的导出全文一致。该结果独立于浏览器下载验证。

Windows 默认入口仍为 `handoffdesk desktop`，使用 WebView2 承载 Web UI。旧 Tk 入口保留为 `legacy-desktop`，仅在全量套件中继续运行兼容性测试。

## 验收边界

- 会话恢复候选由 Agent 明确选择，无宿主 ID 时不凭同名任务自动合并。
- 文件不超过 1 MiB 时记录内容 hash，更大文件按大小和修改时间比较；旧记录缺少基线时显示未知。证据副本只保存主动操作时的当前普通文件，上限 10 MiB，不还原过去版本，也不提供防篡改存储。
- 搜索以流式解析方式筛选可见字段，尚未进行大数据量性能验收。
- 安装验证使用 editable 源码；未验收发行安装包首装、升级、卸载，真实 Codex 信任与自动 hooks、外部应用打开和定位、系统 DPI、Linux 实机及长期负载。
- 此处仅报告本地结果，不代表 GitHub 托管 CI 已通过。
